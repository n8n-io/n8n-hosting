Changed:
  - Removed database.useExternal. database.type chooses the database. Your connection settings stay as they are.
Check:
  - Task runners are on by default in 2.0 and need a token. Add N8N_RUNNERS_AUTH_TOKEN to the Secret n8n-core-secrets. Or set taskRunners.authToken.existingSecret to another Secret that holds it, or set taskRunners.enabled: false. The chart cannot see into the Secret, so the render passes, but the pods do not start without the key.
