Check:
  - env.shared.DB_POSTGRESDB_HOST was a reference, and chartEnvOverrides takes only literal values. The script removed it, so the chart sets DB_POSTGRESDB_HOST from database.host. Set database.host to choose the value.
  - env.shared.N8N_ENCRYPTION_KEY was removed, because the chart reads N8N_ENCRYPTION_KEY from a Secret. In 1.x n8n read it from the key encryption-key in the Secret n8n-key. Put the same value in a Secret under the key N8N_ENCRYPTION_KEY, and set secretRefs.existingSecret to that Secret, or set secretRefs.env.N8N_ENCRYPTION_KEY to it. With a different key, n8n cannot decrypt the credentials it saved.
  - env.webhookProcessor.DB_POSTGRESDB_PASSWORD was removed, because the chart reads DB_POSTGRESDB_PASSWORD from a Secret. Set database.passwordSecret.name and database.passwordSecret.key to the Secret and key that hold the same value.
